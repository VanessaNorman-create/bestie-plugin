# Bestie App plugin

The Bestie App plugin for Claude Co-Work. It connects to your Bestie App and helps
you write your content in your own business's voice.

Everything the plugin does requires your personal **connection code** from the
Start here page in your Bestie App. Without a code it does nothing, and it carries
no instructions or secrets: those live securely on the server.

Install from the marketplace, then type `/bestie-connect` and paste your connection code.
